# Media in the app's one bucket

<!-- Generated by php artisan standards:install from tey/standards; do not edit. -->

Media Library writes to a rooted media disk, never the whole bucket: a `media` scoped disk with prefix `media` over the base disk MEDIA_DISK names (driver scoped, disk env('MEDIA_DISK'); requires league/flysystem-path-prefixing), since Laravel Cloud names an attached bucket's disk when it is attached; storage/app/private/media locally, and media-library.disk_name set to media; s3 stays the whole bucket for the app's own files. Use a new disk, not Media Library's prefix, so existing rows keep resolving on the disk they name. Follow the recipe "Media in the app's one bucket".
