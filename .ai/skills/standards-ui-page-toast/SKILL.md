# Toast feedback

<!-- Generated by php artisan standards:install from tey/standards; do not edit. -->

Headless kit toasts (tey/kit 0.4.6+): the controller decides, through Toastable `$this->toast(...)` or `Toast::success|info|warning|error`, and the shell's one Toaster renders the flash; pages never call a useToast(). Toast saves and background or async results (Import finished, Export ready). Errors are validation or inline responses next to the field or row, never a toast alone; navigation is never toasted, the new page confirms it. Styles: pulse is the default for saves, with `->from('<action id>')` naming the descriptor key of the button that saved; anchored for table row actions and inline toggles; fly-out only by choice, when the movement should draw the eye; plain for background results and anything without a trigger (also the fallback when the trigger is missing or offscreen). Placement is shell-level `kit.toasts.position` (KIT_TOASTS_POSITION: auto, top-center, top-right, bottom-right, bottom-center), set per app and never per page. auto resolves as: under sm, bottom-center above sticky bars (for every position); sticky bottom bars plus right-aligned header actions, top-center; sticky bottom bars only, top-right; otherwise bottom-right. At most one action (label, href, optional get/post/put/patch), never destructive: a delete method or a delete/remove/discard/revoke label is refused, and a destructive step needs a confirmation instead.

Scaffold: `php artisan standards:make page --flavor=form <Name>`.

Kit: @kit/ui Toaster, Tey\Kit\Features\Core\Toast, Tey\Kit\Features\Core\Concerns\Toastable.
- `Toaster` from `@kit/ui` for the toaster: The one shell mount (Workspace Layout, GuestShell, or a host's own focus shell); never mounted per page (props: none; position comes from kitToasts).
- `InertiaAction` from `@kit/ui` for the save trigger: The named Save action in the header #actions slot or FormActions; its data-action is what ->from('<action id>') anchors the pulse or bubble to (ui-page.header-actions: actions written out by name, not a catch-all ActionBar) (props: the save Action descriptor).
- `RowActions` from `@kit/ui` for the row trigger: Row actions whose result shows as an anchored bubble on the right row (props: actions descriptors).
